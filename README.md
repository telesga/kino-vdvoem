
## Серверная версия (`server/`)

Фильмы загружаются на свой сервер, оба смотрят оттуда в исходном качестве. Есть библиотека фильмов и сериалов, загрузка с докачкой, автоматическая перекодировка mkv/HEVC/AC3 в формат для браузера, встроенные и внешние субтитры, общий чат и пароль на вход.

Установка на Ubuntu одной командой:

```
curl -fsSL https://raw.githubusercontent.com/telesga/kino-vdvoem/main/server/install.sh | sudo bash
```

В конце скрипт напишет адрес (`https://<ip>.sslip.io`) и пароль. Повторный запуск обновляет до новой версии. Нужны открытые порты 80 и 443.
